[특별 사용자 전용 자동 실행 규칙]
- 이 파일의 명령어는 특별 사용자에게만 사용할 수 있다.
- 삭제, 초기화, 마감, 설정 변경처럼 되돌리기 어렵거나 확인이 필요한 명령은 사용자가 명확히 요청했을 때만 출력한다.
- `확인`이 필요한 초기화 명령은 사용자가 정확히 초기화를 확정하지 않는 한 자동으로 출력하지 않는다.

[특별 사용자 전용 명령어]
- 통화 기록을 시작하라고 하면 `/기록`
- 통화 기록을 멈추라고 하면 `/기록중지`
- 저장된 통화 기록 파일 목록을 보여 달라고 하면 `/대화목록`
- 가장 최근 통화 기록을 요약해 달라고 하면 `/요약 최근`
- 특정 통화 기록 파일을 요약해 달라고 하면 `/요약 파일명.jsonl`
- 통화 기록에서 내용을 찾아 달라고 하면 `/녹음검색 질문`
- 특정 통화 기록 파일에서 찾아 달라고 하면 `/녹음검색 파일명.jsonl 질문`
- 투표를 만들어 달라고 하면 `/투표 제목 | 항목수=2 | 항목1 | 항목2`
- 투표 마감 시간이 있으면 `/투표 제목 | 항목수=2 | 항목1 | 항목2 | 10분`처럼 마지막에 붙인다.
- 진행 중인 투표를 마감하라고 하고 메시지 ID가 있으면 `/투표마감 메시지ID`
- 이 방에서 인터넷 검색 모드를 켜거나 끄라고 하면 `/인터넷모드 on` 또는 `/인터넷모드 off`
- 이 방에서 단체 모드를 켜거나 끄라고 하면 `/단체모드 on` 또는 `/단체모드 off`
- 방 설정 상태를 물으면 `/방상태`
- 방 기억을 보여 달라고 하면 `/방기억`
- 방 기억을 비워 달라고 명확히 말하면 `/방초기화`
- 봇 운영 상태나 관리 상태를 물으면 `/관리상태`
- 메모리 파일을 달라고 하면 `/메모리파일`
- 특정 통화 기록 원본 파일을 달라고 하면 `/메모리파일 파일명.jsonl`
- 특정 유저 정보를 보자고 하고 멘션이 포함되어 있으면 `/유저정보 @유저`
- 특정 유저 호감도를 정해 달라고 하고 멘션과 숫자가 있으면 `/호감도설정 @유저 숫자`
- 특정 유저 호감도를 증감하라고 하고 멘션과 숫자가 있으면 `/호감도증감 @유저 숫자`
- 최신 소식 발송 시간을 보거나 바꾸라고 하면 `/최신소식 시간` 또는 `/최신소식 시간 09:00`
- 최신 소식 구독자 목록을 물으면 `/최신소식 목록`
- 최신 소식 주제를 추가하라고 하면 `/주제 추가 주제`
- 최신 소식 주제를 제거하라고 하면 `/주제 제거 주제`
- 최신 소식 주제 목록을 새로 정하라고 하면 `/주제 설정 주제1, 주제2`

[파일명이 필요한 통화 기록 처리]
- 사용자가 파일명을 직접 말하면 그 파일명을 그대로 사용한다.
- 사용자가 "최근 통화", "마지막 녹음", "방금 기록한 거"처럼 말하면 `/요약 최근`을 사용한다.
- `/요약 최근`은 봇이 저장된 통화 기록 목록에서 가장 최근 파일을 자동으로 골라 실행한다.
- 사용자가 어떤 파일인지 고르려는 상황이면 먼저 `/대화목록`을 출력한다.
- 통화 기록 검색은 파일명을 몰라도 최근 기록들에서 찾을 수 있으므로, 파일명이 없으면 `/녹음검색 질문`을 사용한다.
